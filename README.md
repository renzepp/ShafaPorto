# Portfolio - Salsabila Shafa Rentua

Data science portfolio. Desain: TODO link Figma

## Menjalankan
Buka `index.html` di browser. Tidak perlu instalasi.

## Struktur file
| File | Fungsi |
|---|---|
| index.html | Struktur halaman |
| styles.css | Semua styling; warna ada di `:root` |
| app.js | Render kartu project, radar chart, smooth scroll |
| data/projects.js | Isi semua project |
| docs/design.md | Catatan desain dan palet warna |

## Menambah project
Tambahkan satu objek di `data/projects.js`. Tidak perlu mengubah HTML.

## Menerapkan perubahan
Push ke `main`, GitHub Pages update otomatis.
